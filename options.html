GPG commit signing optional

Sign commits with your GPG key so they show as "Verified" on GitHub. Replace the stub lib/openpgp.min.mjs with the real openpgp library, then reload extension.

How it works

When you browse itch.io, the extension automatically detects free game pages and adds them to a local queue. Once the queue reaches 15 links, it pushes them to your GitHub repository's temp_link.json file. Your existing GitHub Actions workflow then scrapes the game details.
